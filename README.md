The application helps a restaurant chef capture and view menu items digitally. It replaces a paper-based menu-management process with a simple and user-friendly mobile interface.
The application enables the chef to manage menu items efficiently by entering the dish name, providing a detailed description, selecting the appropriate course category—Starter, Main Course, or Dessert—and specifying the dish price. It also supports adding multiple items to the menu and viewing all previously added entries. The system offers helpful validation messages when required information is missing or incorrect, provides confirmation once a menu item has been successfully added, and displays an appropriate notification when no items are available in the menu.
CHANGELOG
-Although the initial plan in Part 1 was to implement a Picker component for choosing the course, this was revised in Part 2 in favor of a Dropdown component. The change was made because the Dropdown offers a more straightforward and visually clear method for selecting between Starter, Main Course, and Dessert, ultimately improving the chef’s overall interaction with the form.
-The colour palette was simplified in response to feedback on interface‑design principles. The updated design now uses neutral background and content colours, dark text for readability, a single dark‑green accent colour, and red exclusively for validation errors. Additional improvements were made to spacing, alignment, contrast, and overall consistency to create a cleaner and more accessible interface.
